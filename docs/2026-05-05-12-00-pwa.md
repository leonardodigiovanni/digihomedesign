# PWA — DIGI Home Design

**Data:** 2026-05-05  
**Stato:** completato

---

## Obiettivo

Rendere il sito Next.js installabile come Progressive Web App su Android (e iOS parzialmente), distribuibile via QR code che punta all'APK o alla pagina di installazione.

---

## File coinvolti

| File | Operazione |
|------|-----------|
| `app/manifest.ts` | Nuovo — Web App Manifest (nativo Next.js App Router) |
| `public/sw.js` | Nuovo — Service worker minimale (richiesto per il prompt "Installa") |
| `components/pwa-register.tsx` | Nuovo — Client component che registra il SW |
| `app/layout.tsx` | Modifica — aggiunge `<meta name="theme-color">` e monta `<PwaRegister />` |
| `app/app-download/page.tsx` | Nuovo — pagina pubblica con QR code e istruzioni installazione |
| `public/images/icons/` | Nuovo — icone 192×192 e 512×512 (usano immagine esistente come base) |

---

## Passi principali

### 1. `app/manifest.ts`
Next.js App Router espone automaticamente `/manifest.webmanifest` da questo file.
Campi chiave:
- `name`: "DIGI Home Design"
- `short_name`: "DIGI"
- `start_url`: "/"
- `display`: "standalone" (nessuna barra browser — sembra app nativa)
- `theme_color`: "#1c1c1c" (come il footer)
- `background_color`: "#ffffff"
- `icons`: 192×192 e 512×512

### 2. `public/sw.js`
Service worker minimale. Non serve cache offline complessa — serve solo per soddisfare il requisito "app installabile" di Chrome/Android. Intercetta fetch e lascia passare tutto, registra solo l'evento `install`.

### 3. `components/pwa-register.tsx`
`'use client'` — registra `sw.js` via `navigator.serviceWorker.register('/sw.js')` in `useEffect`. Montato nel layout globale (solo lato client, senza impatto SSR).

### 4. `app/layout.tsx`
- Aggiunge `<meta name="theme-color" content="#1c1c1c" />` tramite il `viewport` export
- Monta `<PwaRegister />` in fondo al body

### 5. `app/app-download/page.tsx`
Pagina pubblica raggiungibile via QR:
- Mostra il QR code (immagine statica generata una volta) che punta a `https://www.digi-home-design.com`
- Istruzioni testuali per Android ("Apri Chrome → menu ⋮ → Aggiungi a schermata Home") e iOS ("Apri Safari → condividi → Aggiungi a schermata Home")
- Bottone "Apri l'app" che porta alla home

### 6. Icone
Copio/rinomino l'immagine esistente `public/images/opengraph/big_digi_tr.png` come icone placeholder. Per la produzione andranno create icone quadrate dedicate.

---

## Scelte tecniche

- **No `next-pwa`** — libreria pesante e non più attivamente mantenuta per Next.js 13+. Manifest nativo + SW manuale è sufficiente per installabilità di base.
- **No offline caching** — il sito richiede DB per tutto, la cache offline sarebbe parzialmente inutile. Si può aggiungere dopo.
- **QR code** — generato tramite `qrcode` npm package lato server, salvato come immagine statica in `public/`. In alternativa si usa un'immagine SVG inline.

---

## Risultato atteso

- Su Android (Chrome): banner "Aggiungi a schermata Home" appare automaticamente dopo qualche visita
- L'icona DIGI appare nella home del telefono
- L'app si apre senza barra del browser in modalità standalone
- La pagina `/app-download` con QR è linkabile dal sito e stampabile
