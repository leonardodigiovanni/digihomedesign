# PWA — Layout dedicato /app

**Data:** 2026-05-05  
**Stato:** completato

## Obiettivo
Creare un'area `/app` separata dal sito, con layout proprio e classi CSS prefissate `app-` che non interferiscono col sito.

## Struttura
- `app/app/layout.tsx` — layout PWA (overlay fisso che copre il root layout)
- `app/app/page.tsx` — pagina di benvenuto `/app`
- `app/app/app.css` — classi CSS `app-*` dedicate
- `app/manifest.ts` — `start_url` aggiornato a `/app`

## Scelta tecnica
Il root layout (`app/layout.tsx`) avvolge tutto in Next.js App Router e non si può bypassare senza middleware. Soluzione: il PWA layout usa `position: fixed; inset: 0; z-index: 9999` per coprire visivamente il root layout. Zero modifiche al sito esistente.
